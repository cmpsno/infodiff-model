The concept graph

The network is a hand-built concept graph for one learning domain: Fourier / sine waves. Five core concepts (frequency, amplitude, phase, superposition, spectrum) and four misconceptions from an adaptive tutor's taxonomy — M1 (faster wiggle = taller wave), M2 (adding waves adds their frequencies), M3 (phase shift changes pitch), M4 (a square wave contains one frequency). Edges are prerequisite links.

Here, the rings let you see whether understanding stays inside the core concepts or jumps to the misconceptions: a misconception node lighting up means it got resolved. Misconceptions carry higher thresholds — they only resolve once most of their prerequisites are mastered.
